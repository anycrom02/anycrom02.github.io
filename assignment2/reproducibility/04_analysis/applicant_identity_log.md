# 전체 선정기록 KIPRIS 출원인 식별 로그

- 확인일: 2026-09-30 (Asia/Seoul)
- 입력: Master v7 master_company 83건 및 applicant_identity_pilot.csv 16행/10개 선정기록.
- 범위: 출원인 식별번호·이름·대표 출원 표본만 확인. 전체 특허목록 수집, EDA 및 Master/파일럿 수정 없음.
- 추가 근거 보존: applicant_identity_research.json. KIPRIS 입력 도우미의 실제 응답을 보존. 브라우저 세션 URL이므로 URL만으로 검색조건을 재현하지 못할 수 있으며 source_search_expression을 함께 사용.

## 판정과 데이터 구조

- 확정: 기존 파일럿 확정 결과 재사용 또는 KIPRIS 사업자번호 직접 연결 및 대표 출원 확인. 코난테크놀로지는 DART 법인번호 연결로 확정.
- 조건부: 디브레인 개인·법인 연결/승계 범위 미확인 또는 인텔릭스 연결 근거가 2차 기업정보에 한정.
- 보류: 파일럿에서 대상과 식별번호가 다른 동명·유사 법인. 이 행들은 candidate_role=excluded이며 검토 큐에 넣지 않음.
- 미발견: 충분한 조회 후 후보 자체를 찾지 못한 경우. 사업자번호 0건만으로 미발견 판정하지 않음. 이번 최종 결과에는 없음.
- full.csv는 후보/코드 단위. identity_status는 행별 판정이고 selection_status는 83개 선정기록별 처리상태로 같은 ID의 모든 행에 반복. 제외 후보의 보류가 선정기록 전체를 보류로 바꾸지 않음.
- business_registration_no는 후보 주체 번호; master_business_registration_no는 선정 당시 기준 번호. 디브레인은 두 번호를 분리.
- collection_eligible=Y는 확인된 코드 범위만 허용. 명칭 이력 검토가 남아도 동일 코드의 직접 연결이 확정되면 코드 범위의 출원인 수집은 가능. 현재 권리 귀속 및 다른 주체 승계는 별도.
- 확인되지 않은 법인번호·상세 URL·구사명·표본번호를 추정 입력하지 않음. 파일럿 법인번호 빈칸은 그대로 유지.

## 배치 진행

- 파일럿: 10개 선정기록 16행의 근거·확정/조건부/제외 결과 재사용.
- 신규 배치: 파일럿 제외 73개 선정기록을 selection_id 순서로 30/30/13건 처리. 실행 호출은 각 배치 내 소단위로 나눔.
- KIPRIS 상세검색 > 인명정보 출원인(AP) 입력 도우미에서 사업자번호를 하이픈 없이 조회. 화면에서 번호 검색 지원을 직접 확인함. 특허 결과 검색의 AP에 사업자번호를 대신 넣지 않음.
- 사업자번호 조회: 신규 73개 기록 중 71개에서 후보 발견(빅텍은 코드 2개). 코난테크놀로지·인텔릭스 0건은 이름 및 법인번호 조회로 추가 조사.
- 대표 표본: 새로 발견한 74개 코드 각각 AP=[코드] 검색의 대표 출원 1건 확인. 국내 특허·실용신안 기본 화면의 전체 행정상태. 특허 모집단·전체 건수 또는 공개 A공보 존재를 확정하는 작업이 아님.
- 디브레인 선정 당시 사업자번호도 추가 조회했으나 0건. 기존 조건부 근거를 확정으로 올리지 않음.
