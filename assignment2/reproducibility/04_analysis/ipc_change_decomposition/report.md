# G06N·G06T 비중 증가: 기업 내부 변화와 기업 구성 변화의 분해

분석일: 2026-10-01 KST. 비교기간: 기존 EDA와 같은 **2014~2018년 / 2019~2024년**. 기존 EDA의 코드·표·그림·보고서와 원본 데이터를 보존하고, 이 질문에 필요한 분해만 별도 수행했다.

## 결론

**G06N은 이미 이 기술 비중이 높았던 공통 기업들의 출원량 비중 확대가 주요 요인이다. G06T는 후기 기간에만 출원이 관측된 기업들의 기여와 공통 기업 내부의 영상처리 비중 증가가 함께 나타난다.** 따라서 두 코드를 같은 종류의 '기업 내부 기술 전환'으로 해석하면 안 된다.

대칭 중간값 분해에서 G06N 증가의 68.3%는 공통 기업 간 출원량 가중치 변화, 29.2%는 후기 관측기업 구성, 2.6%는 공통 기업 내부 비중 변화로 배분된다. G06T에서는 각각 9.8%, 47.6%, 42.6%다. 이 수치는 회계적 분해 규칙에 따른 기여율이며 인과적 효과나 유일한 배분율이 아니다. 특히 내부 변화와 출원량 변화가 동시에 일어나므로 두 항목의 정확한 배분은 순서에 민감하다.

## 최소 추가 분석의 범위

- 기존 `04_analysis/eda/patent_company_analysis.csv`의 기업 연결을 재사용했다.
- 원본 `patent_metadata_full.csv`에서 다중 IPC를 읽어 기존 EDA와 같은 서브클래스 분수계수를 계산했다. 대표 IPC 하나만 사용하지 않았다.
- 기간별 고유 출원은 **605건 / 1,993건**이며 기존 EDA의 G06N·G06T 전체 비중을 오차 없이 재현했다.
- 두 기간 모두 출원이 관측된 기업은 **65개**, 후기 기간에만 관측된 기업은 **14개**, 전기 기간에만 관측된 기업은 **0개**다. 합계 79개는 해당 두 기간에서 출원이 있는 기업의 수다.
- 공통 기업의 후기 출원 가중치는 전체의 **79.90%**, 후기 관측기업은 **20.10%**다. 기업의 신규 설립·선정·시장 진입이 아니라 **이 자료에서 해당 기간 출원의 관측 여부**로 집단을 구분했다.

## 집계와 분해 방식

공동출원 하나가 여러 선정기업에 연결되면 해당 출원은 기업들에 균등 분할했다. 기업 연결이 m개인 출원은 각 기업에 1/m건, 그 출원의 IPC 서브클래스가 k개이면 목표 코드의 가중치는 추가로 1/k이다. 이 방식은 기업별 가중치로 합산해도 전체 고유 출원 기준 IPC 비중을 정확히 유지한다. 따라서 후기 기업집단의 출원량은 공통 기업 1,592.5건 상당, 후기 관측기업 400.5건 상당이다. 이것은 정수 출원의 관측 건수가 아니라 분할된 귀속량이다.

회사 i의 기간 t 내부 목표 IPC 비중을 s_it, 공통기업 집단 내부 출원량 비중을 w_it, 전체 출원 중 공통기업 집단의 비중을 alpha_t라 하자. 공통기업 집단의 전체 IPC 비중은 C_t = sum_i(w_it × s_it)다. 전체 기간별 목표 IPC 비중은 S_t다. 막대기호는 두 시점의 단순 평균이다.

공통 기업 비중의 변화는 다음과 같이 정확히 나뉜다.

```
Delta C = sum_i(mean(w_i) × Delta s_i)
        + sum_i(mean(s_i) × Delta w_i)
```

이를 전체 포트폴리오 수준으로 옮긴 기여는 다음과 같다.

```
동일 기업 내부 변화 = mean(alpha) × sum_i(mean(w_i) × Delta s_i)
공통 기업 출원량 가중 변화 = mean(alpha) × sum_i(mean(s_i) × Delta w_i)
후기만 관측된 기업 구성 = 후기 집단 비중 × (후기 집단 IPC 비중 - mean(C))
전기만 관측된 기업 구성 = -전기 집단 비중 × (전기 집단 IPC 비중 - mean(C))
전체 변화 = 위 네 항목의 합계
```

이번 자료에는 전기만 관측된 집단이 없으므로 마지막 항목은 0이다. 공통 집단의 비중 축소도 기업 구성 항목에 포함되며 누락된 별도 잔차는 없다. 전체 변화와 항목 합계의 오차는 1e-12 미만이다.

이 분해는 두 기간을 대칭적으로 처리하고 내부 비중과 출원량 가중치의 상호작용을 반씩 배분한다. 단순히 공통기업 평균을 비교하는 것보다 전체 포트폴리오 비중 변화와 직접 연결된다.

### G06N: 기술 비중이 높은 기업의 출원량 확대가 핵심

공통 기업 중 딥엑스의 출원량은 **2건→103건**, 마키나락스는 **2건→80건**이다. 두 기업은 전기부터 G06N 내부 비중이 높았으며, 분수계수 비중은 각각 **66.67%→52.31%**, **100%→42.50%**로 오히려 낮아졌다. 다만 출원량이 크게 늘면서 전체에서 차지하는 비중이 높아졌다.

대칭 분해에서 딥엑스와 마키나락스의 출원량 가중 변화 기여는 각각 **+3.2842%p**, **+3.0078%p**로, 합계 **+6.2920%p**다. 이는 공통기업 가중 변화 순기여 +6.4057%p의 약 **98.2%**다. 기술 비중은 낮아졌지만 해당 기술의 절대 분수계수는 증가한 사례이므로 비중 감소를 기술 축소나 포기로 해석하지 않는다.

같은 기업 내부 증가도 존재한다. 마크애니의 G06N 비중은 **1.35%→15.91%**, 코난테크놀로지는 **1.47%→27.38%**로 높아졌고 내부 변화 기여는 각각 **+0.6556%p**, **+0.5836%p**다. 다른 기업의 감소와 상쇄되어 내부 변화의 전체 순기여가 작아진 것이다.

후기에만 관측된 기업 구성 중 인피닉은 **+1.6398%p**, 에스아이에이는 **+0.8544%p**를 기여한다. 합계는 후기 집단 구성 순기여의 약 **91.2%**다. 이는 이 두 기업의 설립이나 사업 진입 시점에 대한 주장이 아니다.

### 내부 변화와 출원량 변화의 계산 순서

두 변화가 동시에 발생할 때 상호작용의 배분에는 하나의 필연적인 정답이 없다. 공통기업 분해에서 내부 비중을 먼저 바꾸거나 출원량 가중치를 먼저 바꾼 두 경로도 계산했다. 공통집단 비중과 신규 관측집단 구성은 주 분석과 동일하게 처리한다.

|IPC|내부 변화 기여의 두 경로 범위|가중 변화 기여의 두 경로 범위|후기 관측기업 구성 기여|
|---|---:|---:|---:|
|G06N|-1.5795~+2.0591%p|+4.5864~+8.2250%p|+2.7343%p|
|G06T|+0.7131~+3.1420%p|-0.7705~+1.6584%p|+2.1571%p|

주 분석의 대칭값은 각 두 경로 값의 평균이다. **G06N에서 공통기업 출원량 가중 변화가 가장 큰 항목이라는 결론은 두 경로 모두 유지**된다. G06T 내부 기여는 두 경로 모두 양수지만 기업 구성과 내부 변화 중 어느 쪽이 더 큰지는 배분 규칙에 따라 달라진다. 따라서 G06T의 42.6%와 47.6%를 정밀한 우열로 해석하지 않는다. 표의 범위는 통계적 신뢰구간이 아니라 계산 규칙 민감도다.

## 해석 한계

1. 관측기업 구성 변화는 실제 신규기업 유입·퇴출과 다르다. 전기에 0건이었던 이유는 설립 전, 특허활동 부재, 공개 범위, 과거 코드 연결 누락 등일 수 있다. 설립연도·사업변경은 확인하지 않았다.
2. 기업 내부 IPC 비중은 **해당 기간의 관측 출원 흐름** 구성이다. 보유 중인 유효 특허 자산, R&D 투자배분, 제품 또는 기업전략의 직접 측정이 아니다.
3. 전기에 1~2건만 있는 기업의 비중은 불안정하다. 특히 딥엑스·마키나락스·모라이의 초기 비중에는 소표본 영향이 크다. 수치가 정확해도 안정적인 기술 전문화 추정이라고 보장하지 않는다.
4. 기간 길이는 5년과 6년으로 다르다. 분석은 기간 내 기술 구성비를 비교하며 연간 출원증가율을 비교하지 않는다. 기업별 활동기간 차이도 조정하지 않았다.
5. 공동 선정기업 출원은 균등 귀속했다. 이는 중복 없이 전체 변화를 연결하기 위한 분석 규칙이지 발명 기여·소유지분을 뜻하지 않는다.
6. IPC 다중분류를 균등 배분했고 IPC 버전·과거 재분류를 통일하지 않았다. 기술비중 변화는 현재 표시 IPC 기반이다. 공개 지연, 미수집 2개 기업, 확정 코드 밖의 과거 출원 누락 등 기존 EDA 한계가 유지된다.
7. 본 분석은 정확한 기술통계 분해다. 원인·선정지원 효과·기업의 의도적 기술 전환을 입증하지 않는다. 2.6%·68.3% 등의 배분율은 명시한 대칭 규칙에 조건부다.
